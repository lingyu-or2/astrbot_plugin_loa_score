# astrbot_plugin_loa_score — 命运方舟首饰评分

[![AstrBot 插件](https://img.shields.io/badge/AstrBot-插件-purple)](https://docs.astrbot.app/)
![Version](https://img.shields.io/badge/version-1.0.1-blue)

发送《命运方舟》装备（项链/耳环/戒指/手镯）属性截图，机器人识别词条后按
**lopec.kr 的评分口径**回复评分。评分规则表离线内置（由 lopec 前端逆向数据构建），
识别由当前会话配置的**多模态模型**完成。

## 指令

| 指令 | 说明 |
|---|---|
| `/首饰评分` + 装备截图 | 识别并评分（图片和指令同一条消息） |
| `/首饰评分 [部位] [品级]` | 手动指定 部位（手镯/项链/耳环/戒指）与品级（遗物/古代） |
| `/评分帮助` | 显示帮助 |

## 评分口径（lopec.kr，2026-10-25 前端逆向）

- **项链/耳环/戒指**
  - 主属性百分比 = `(stat − min) / (max − min) × 100`（T4 区间：项链 15178~17857、
    耳环 11806~13889、戒指 10962~12897；遗物/古代共用），保留 2 位小数；
  - 부여 효과 词条按 T4 遗物/古代的 **下/中/上** 数值阶梯评级（16 种词条）；
  - 词条战力倍率按 lopec 权重（额外伤害 0.007692/单位、暴击率 0.007742、
    暴击伤害 0.003、对敌伤害 0.01、攻击力% 0.01）连乘。
- **手镯**
  - 特殊词条按 T4 模板（132 条，语义子句签名匹配）给出 **下/中/上** 评级；
  - 特殊词条战力倍率 = Π(值/10000 + 1)；
  - 属性行（会心/专长/迅捷等）不参与评级（lopec 无手镯属性绝对评级，
    属性影响体现在全角色模拟的「팔찌 효율」中，无法离线计算）。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| vision_enabled | true | 关闭后不调用模型识别截图 |
| vision_provider_id | 空 | 识别专用提供商 ID：填写后截图识别固定走该提供商（聊天仍用会话模型）。适用于会话模型不支持图片、但另配有视觉模型的场景 |

**前置条件**：识别所用模型需支持图片输入（glm-4v / qwen-vl / gpt-4o / gemini 等）。
若会话模型是纯文本模型（如 DeepSeek 系），新增一个视觉模型提供商
（例如智谱 glm-4v-flash 免费、阿里百炼 qwen-vl 系列等），把它的 ID 填进
`vision_provider_id` 即可——聊天与识别各用各的模型，互不影响。

## 依赖

无第三方依赖（aiohttp 由 AstrBot 内置）。

## 局限与说明

- 仅支持 **T4（遗物/古代）** 装备；T3 及更早档位不在规则表内。
- 韩服 lopec 与国服术语存在个别翻译差异，规则表按国服常见译名匹配；
  无法识别的词条会明确列出而不是给出错误评分。
- lopec 口径的「主属性百分比」只衡量主属性档位，与词条好坏无关；
  手镯的「팔찌 효율 %」依赖整卡角色数据，本插件不计算。
- 规则表数据时点 2026-10-25，游戏版本更新后若档位数值变化需重新构建
  （构建脚本会从 lopec 前端重新提取）。
