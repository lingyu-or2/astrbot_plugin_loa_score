# astrbot_plugin_loa_score — 命运方舟首饰评分

[![AstrBot 插件](https://img.shields.io/badge/AstrBot-插件-purple)](https://docs.astrbot.app/)
![Version](https://img.shields.io/badge/version-1.2.2-blue)

发送《命运方舟》装备（项链/耳环/戒指/手镯）属性截图，机器人识别装备名与词条后按
**lopec.kr 的评分口径**回复评分。评分规则表离线内置（由 lopec 前端逆向数据构建），
识别由**多模态模型**完成；提供商与具体模型都可在插件配置里单独指定。
评分结果输出为 3–4 行紧凑格式。

## 指令

| 指令 | 说明 |
|---|---|
| `/首饰评分` + 装备截图 | 识别并评分（图片和指令同一条消息；多图只评第一张） |
| `/首饰评分 [部位] [品级]` | 手动指定 部位（手镯/项链/耳环/戒指）与品级（遗物/古代），顺序不限 |
| `/评分帮助` | 显示帮助 |

截图里能读到装备名时，部位会自动兜底判断（如名称含「项链」）；
读不出部位时才需要手动指定。一次消息里有多张图时只评第一张，其余请分条发送。

## 评分口径（lopec.kr，2026-10-25 前端逆向）

- **项链/耳环/戒指**
  - 主属性百分比 = `(stat − min) / (max − min) × 100`（T4 区间：项链 15178~17857、
    耳环 11806~13889、戒指 10962~12897；遗物/古代共用），保留 2 位小数；
  - 부여 효과 词条按 T4 词条池的 **下/中/上** 数值阶梯评级（18 类，含固定值变体）；
    T4 遗物/古代共用同一套阶梯；
  - 词条战力倍率按 lopec 权重（额外伤害 0.007692/单位、暴击率 0.007742、
    暴击伤害 0.003、对敌伤害 0.01、攻击力% 0.01）连乘；
  - 词条出现在不适用的部位时（如耳环出现「额外伤害」）给出核对提醒，但**不改变评分**。
- **手镯**
  - 特殊词条按 T4 模板（132 条，语义子句签名匹配）给出 **下/中/上** 评级；
  - 特殊词条战力倍率 = Π(值/10000 + 1)；
  - 属性行（会心/专长/迅捷）不参与词条评级；另按 lopec 属性系数
    **每点 +0.03%** 单独展示属性战力，不并入特殊词条合计；
  - 「팔찌 효율 %」依赖整卡角色数据，无法离线计算，本插件不提供。

> 仅支持 **T4（道具阶级 4）**。识别到 T3（道具阶级 3）时直接提示不支持，
> 避免用 T4 区间/阶梯算出失真结果。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| vision_enabled | true | 关闭后不调用模型识别截图 |
| vision_provider_id | 空 | 识别专用提供商：WebUI 里直接下拉选择（兼容填 ID/显示名/模型名）。填写后截图识别固定走该提供商，聊天仍用会话模型；留空则用会话当前模型 |
| vision_model | 空 | 识别模型（可选）：留空用提供商默认模型；填写后透传 `text_chat(model=...)` 强制使用。提供商默认是 `qwen-image`（文生图，不能聊天）或纯文本模型时**必须填写**，例如 `qwen-vl-max`、`qwen-vl-plus`、`glm-4v-flash` |
| vision_timeout | 120 | 识别超时（秒），有效范围 10–600；网络慢或大图可调高 |

**前置条件**：识别所用模型需支持图片输入（qwen-vl / glm-4v / gpt-4o / gemini 等）。
如果提供商默认模型不是看图模型（例如 `qwen-image` 是文生图模型），在
`vision_model` 里填一个视觉模型即可；聊天仍用会话模型，互不影响。
DeepSeek 系模型是否支持图片取决于**具体部署/网关**，不能只看模型名——
以 AstrBot WebUI 聊天页直接发图能否看见为准。

## 局限与说明

- 仅支持 **T4（道具阶级 4，遗物/古代）** 装备；识别到 T3 会直接提示不支持。
- 识别依赖模型对截图的忠实转写；模型漏行/写错数值时会表现为「未匹配档位」
  或在词条与部位不符时给出核对提醒，不会臆造评级。
- 无法识别的词条会明确列出而不是给出错误评分；最多展示 6 条，其余标注数量。
- 一次消息只评分第一张图；多件装备请分条发送。
- 插件保证按 AstrBot 标准 `image_urls` 发送图片；**图片最终是否被模型看到取决于提供商/网关**。
  若模型确实支持视觉却仍回复「未收到图片」，请先用 WebUI 聊天页直接发图验证，
  同为「看不见」则是网关吞图，不是插件问题。
- lopec 口径的「主属性百分比」只衡量主属性档位，与词条好坏无关；
  手镯的「팔찌 효율 %」依赖整卡角色数据，本插件不计算。
- 规则表数据时点 2026-10-25，游戏版本更新后若档位数值变化需重新构建
  （构建脚本会从 lopec 前端重新提取）。
